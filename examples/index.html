Examples

A small set of native custom elements you can import into an HTML page, Astro route, static site, or framework view. No wrapper component is required: the import registers a browser element, and the uix-* tag renders the control.

Use

Import the component entrypoint once, then write ordinary HTML.

Register an element

import "@charliewilco/extensions/slider";

Render it

<uix-slider min="0" max="10" value="4"></uix-slider>
