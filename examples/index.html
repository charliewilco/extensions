Accordion

A single disclosure row with a slotted trigger and panel.

import "@charliewilco/extensions/accordion";
Billing details

Invoices are sent on the first day of each month.

 Deployment window

Production deploys are held while incident review is active.

	<span slot="trigger">Billing details</span>
	<p>Invoices are sent on the first day of each month.</p>
</uix-accordion>

Dialog

A lightweight dialog surface with host methods.

import "@charliewilco/extensions/dialog";

Delete project?

This action cannot be undone.

 
<button id="open-delete-dialog" type="button">Open dialog</button>
<uix-dialog id="delete-dialog">
	<h4>Delete project?</h4>
	<p>This action cannot be undone.</p>
</uix-dialog>

<script type="module">
	import "@charliewilco/extensions/dialog";

	document.querySelector("#open-delete-dialog")?.addEventListener("click", () => {
		document.querySelector("#delete-dialog")?.show();
	});
</script>
